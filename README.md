# 영혼을 울리는 영어 성경 퀴즈 앱

본 프로젝트는 웹 표준 기술을 활용하여 구현된 **대화형 영어 성경 퀴즈 애플리케이션**입니다. 사용자가 성경 구절의 빈칸에 알맞은 단어를 입력하며 학습할 수 있도록 설계되었으며, 학습 데이터와 로직이 결합된 경량형 단일 파일 구조를 취하고 있습니다.

---

## 🚀 프로젝트 개요
성경 구절을 매개로 영어 문장 구조를 익히고 핵심 어휘를 암기하는 데 최적화된 도구입니다. 복잡한 설치 과정 없이 웹 브라우저만으로 즉시 실행이 가능하며, 사용자 경험(UX)을 고려한 직관적인 디자인을 제공합니다.

---

## ✨ 주요 기능

### 1. 지능형 퀴즈 시스템
*   **빈칸 학습**: 성경 구절 중 핵심 키워드를 빈칸으로 처리하여 문맥 파악 능력을 향상시킵니다.
*   **실시간 정답 확인**: 입력 즉시 정답 여부를 판별하여 시각적 피드백을 제공합니다.
*   **자동 문항 전환**: 정답 확인 후 일정 시간(2초)이 지나면 자동으로 다음 문항으로 이동하여 학습 흐름을 유지합니다.

### 2. 학습 성과 관리
*   **실시간 스코어링**: 퀴즈 진행 상황과 현재 점수를 상단 배지에 실시간으로 노출합니다.
*   **최종 결과 보고**: 모든 문항 완료 시 최종 점수와 함께 성취도에 따른 맞춤형 축하 메시지를 출력합니다.

### 3. 사용자 인터페이스 (UI)
*   **모던 카드 레이아웃**: 30px의 둥근 모서리와 깊이감 있는 그림자 효과를 적용한 카드 디자인을 채택했습니다.
*   **반응형 레이아웃**: 모바일 및 데스크톱 환경에 최적화된 뷰포트를 지원합니다.

---

## 🛠 사용 기술 (Tech Stack)

| 구분 | 기술 스택 | 설명 |
| :--- | :--- | :--- |
| **Markup** | **HTML5** | 애플리케이션 프레임워크 및 데이터 구조 정의 |
| **Styling** | **CSS3** | 카드 레이아웃, 그라데이션, 애니메이션 및 테마 스타일링 |
| **Scripting** | **JavaScript (ES6+)** | 상태 관리, 데이터 처리 로직 및 동적 DOM 조작 |

---

## 📦 설치 및 실행 방법

이 프로젝트는 단일 `index.html` 파일로 구성되어 있어 별도의 서버나 빌드 도구가 필요하지 않습니다.

1.  본 저장소의 `index.html` 파일을 로컬 저장소로 다운로드합니다.
2.  파일을 더블 클릭하거나 웹 브라우저(Chrome, Edge 등)로 드래그 앤 드롭하여 실행합니다.
3.  화면의 안내에 따라 영어 단어를 입력하고 학습을 진행합니다.

---

## 🎨 디자인 사양 (Design Specifications)

*   **Background Color**: `Light Pink (#fff0f3)` - 시각적 편안함을 주는 파스텔 톤 테마
*   **Card Design**: `border-radius: 30px`, `Deep Shadow` 적용으로 입체감 강조
*   **Typography**: 가독성이 높은 `Helvetica Neue` 기반 산세리프 서체
